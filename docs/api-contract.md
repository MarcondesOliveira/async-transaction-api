# API contract

## Common conventions

- JSON uses camelCase properties.
- Dates use ISO 8601 UTC.
- Monetary values are strings with exactly two decimal places.
- Transaction statuses are uppercase strings.
- Unknown JSON properties are rejected.

## `POST /transactions`

Required headers:

- `Content-Type: application/json`
- `Idempotency-Key`: 8 to 128 printable ASCII characters without spaces

Optional header:

- `X-Correlation-Id`: UUID; generated by the API when absent

Validation:

- `transactionType`: `TRANSFER`
- `amount.value`: greater than zero, at most 12 integer digits and exactly 2 decimals
- `amount.currency`: `BRL`
- `destination.accountId`: 1 to 64 characters
- `externalReference`: optional, at most 100 characters

Responses:

| HTTP | Code | Meaning |
|---:|---|---|
| `202` | — | Transaction accepted or identical idempotent replay. |
| `400` | `VALIDATION_ERROR` | Invalid header, identifier or payload. |
| `409` | `IDEMPOTENCY_KEY_REUSED` | Key already used with different content. |
| `500` | `INTERNAL_ERROR` | Unexpected failure. |

## `GET /transactions/{transactionId}`

Responses:

| HTTP | Code | Meaning |
|---:|---|---|
| `200` | — | Current transaction representation. |
| `400` | `VALIDATION_ERROR` | `transactionId` is not a UUID. |
| `404` | `TRANSACTION_NOT_FOUND` | Transaction does not exist. |
| `500` | `INTERNAL_ERROR` | Unexpected failure. |

## Error body

```json
{
  "code": "VALIDATION_ERROR",
  "message": "The request contains invalid fields",
  "correlationId": "f452ea72-e88d-48e9-875f-3f5e7f2736e6",
  "details": [
    {
      "field": "amount.value",
      "message": "Value must be greater than zero, contain up to 12 integer digits and exactly two decimal places"
    }
  ]
}
```

See the [cross-service contracts and state transitions](https://github.com/MarcondesOliveira/async-transaction-infrastructure/blob/main/docs/contracts.md)
for the request event, simulator submission, callback event, retry rules and
retention boundaries. The API stores `externalReference`, but the current Pipe
does not propagate it to the processor.
